# Campaign links (UTM)

This folder is not part of the website build. Nothing here appears on tarkasatales.com.

Use these links when you share the website, so Umami can show which channel brought each visitor (Umami → UTM). They never change what the visitor sees.

**Rules:** lowercase only, hyphens not spaces. `utm_source` = where (instagram, youtube, learning-club), `utm_medium` = what kind (social, video, email), `utm_campaign` = which push (a month like `2026-12`, or a book id like `marie-curie`).

## Ready to use

| Where | Link |
|---|---|
| Instagram bio | `https://tarkasatales.com/?utm_source=instagram&utm_medium=social&utm_campaign=bio` |
| Instagram reel or post about one book | `https://tarkasatales.com/books/BOOK-ID/?utm_source=instagram&utm_medium=social&utm_campaign=BOOK-ID` |
| Instagram story about free printables | `https://tarkasatales.com/activities/?utm_source=instagram&utm_medium=social&utm_campaign=printables` |
| YouTube video description | `https://tarkasatales.com/books/BOOK-ID/?utm_source=youtube&utm_medium=video&utm_campaign=BOOK-ID` |
| Learning Club email (each link) | `…?utm_source=learning-club&utm_medium=email&utm_campaign=2026-12` (change the month) |
| Welcome email | `…?utm_source=learning-club&utm_medium=email&utm_campaign=welcome` |
| School or library flyer (QR code) | `https://tarkasatales.com/?utm_source=flyer&utm_medium=print&utm_campaign=schools` |
| LinkedIn post | `https://tarkasatales.com/?utm_source=linkedin&utm_medium=social&utm_campaign=MONTH` |

Book ids: `marie-curie`, `albert-einstein`, `jane-goodall`, `isaac-newton`, `katherine-johnson`, `george-washington-carver`, `mae-jemison`, `alexander-fleming`, `galileo-galilei`, `ada-lovelace`, `bobbin-and-the-wobble-bridge`, `hanuman-ocean-leap`, `bobbins-feelings-pocket` (coming soon), `shiva-river-from-sky` (coming soon), `shabari-forest-welcome` (coming soon).

## Links straight to Amazon

Prefer linking to the book page on our site (it shows every country's store and counts the click). If you link straight to Amazon, UTM tags don't work there. Use an **Amazon Attribution** tag link instead, if you have Attribution (see `analytics-guide.md`).
